03 — CONTRACTS

provider preset と横断機構

Preset は必須 trait 3 個と optional capability を束ね、同じ route の状態も所有する。

Auth

Wire が作った request に request-time 認証を適用する。

Wire

Messages 正規形を upstream request へ encode し送信する。

Metering

quota、拒否、本文 usage、model 単価を応答から読む。

QuotaApi optional

枠照会 API と最小 probe request。能力が無ければ None。

Negotiation optional

request header の準備と、400 応答からの学習。

RouteState

denial、quota snapshot、background probe の予定を preset 内に保持。

core が 1 本だけ持つ横断機構

Affinity

session から provider をまたいで route を選ぶため Router が持つ。

Event bus

各 route と router が発火し、購読者には 1 本の stream として見せる。

Stats writer

provider が抽出した正規 usage を日 × credential × model へ合流させる。

Quota store

route が持つ snapshot を再起動越しに保存・復元する。

集計正規形

TokenKind(String) + BTreeMap

既知区分の綴りは constructor で揃え、未知区分も落とさず保持する。料金は Pricing::rates に明示された区分だけを合計するため、親区分と subset の内訳が同居しても二重課金しない。
