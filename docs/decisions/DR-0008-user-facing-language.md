# DR-0008: プログラムが出す文言は英語にする

- Status: Active
- Date: 2026-07-29

## Context

`/llm-gateway/usage` の JSON に `"note": "対象外 (AWS 課金)"` のような日本語を入れたところ、
kawaz から方針が出た。

> json のステータスにこの程度の長さに日本語混ぜるのやめてくれませんかね。
> もっと長いやつとかならまだしも。日本語はコメントやドキュメントやチャットで十分で、
> error message とか cli help とかは普通に英語で良いです。

## Decision

| 出力先 | 言語 |
|---|---|
| JSON のフィールド値 (status / note 等の機械が読む・短い値) | **英語** |
| error message | **英語** |
| CLI の help・ラベル・表ヘッダ | **英語** |
| ログ (tracing) | **英語** (2026-08-14 kawaz 裁定で対象に追加) |
| コードコメント・docs/・DR・チャット | **日本語** (従来どおり) |

**適用は「新規に書く文言から」** (kawaz: 「今はいいか」「スピード重視で良いや」)。
既存文言の一括置き換えは行わず、該当コードを触ったついでに直す。
残件は `docs/issue/` で追跡する。
