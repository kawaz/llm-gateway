# DR-0015: routing のネストグループと 7d リセット期限優先の動的順序

- Status: Accepted
- Date: 2026-08-12

## 背景

routing rule の `routes = [...]` は「並び順 = 優先順」の固定順序で、枠の
状況に応じた使い分けができない。実運用で「kawazzz より zunsystem の方が
7d リセットが近いのに、順序が先頭固定のせいで kawazzz から消費される」
状態が起き、リセットで消える残枠を取りこぼす損が出た (kawaz 指摘 2026-08-11)。

7d 窓の全枯渇は実質的な活動停止に直結するため、「リセットが近い credential
から使い切る」を自動化する (kawaz 裁定: 見るのは 7d 窓のみ。5h 窓は数時間で
回るので使い切り戦略の対象にしない)。

## 決定

### 1. `routes` 配列の要素にネスト配列 (同格グループ) を書ける

```toml
[[ns.personal.routing]]
models = ["claude-fable-*"]
# 内側の [] は同格グループ。7d リセットが近い方から使う。
routes = [
    ["claude-zunsystem", "claude-kawazzz"],
    "claude-emrd",
    "bedrock",
    "bedrock-use1",
]
```

- **外側の並び順 = 優先順** (従来のフラット形式の読みそのまま)。文字列
  要素は「要素 1 個の同格グループ」と等価で、フラット配列は全要素が
  単独グループの退化形として包含される
- **内側の配列 = 同格グループ**。グループ内の全 route を使い切ってから
  次の要素へ進む (グループ間は従来の fallback と同じ)
- ネストは 1 段まで。グループの中にグループは書けない (エラー)

### 2. 同格グループ内は 7d リセットが近い順

- 並び替えキーは quota スナップショット ([`Snapshot::seven_day`] の
  `reset`、Unix 秒)。**小さい (= リセットが近い) credential を先に使う**。
  リセットで消える残枠から先に消費するため
- 7d reset が読めない candidate (スナップショット無し / 窓情報無し /
  reset が現在時刻より過去 = 陳腐化) は、読めた candidate 群の**後ろ**に
  グループ内記載順で並ぶ
- 仕組みは provider 非依存 (kawaz 指摘 2026-08-11: codex でも同じことが
  言える)。キーは core の [`Snapshot`] であり、claude OAuth / codex OAuth
  いずれの credential でもグループ化すれば同じ挙動になる。各 preset の
  Metering / QuotaApi が 7d reset をスナップショットに書けていることが前提
- 並び替えは**候補列の順序決定のみ**に作用する。既存の 429 締め出し
  (DR-0009)、session affinity、ResponseAdmission (DR-0014 §9) の挙動は
  変えない — それらが除外した残りに対して順序を適用する

## 採らなかった案

- **数値 `priority` 属性**: 「数字が大きい方が優先か小さい方か」の曖昧さが
  本質的に残る (kawaz 指摘)。`rank` / `tier` 等への改名でも慣習の衝突は
  解消しない。ネスト配列は方向を示す数値・語彙が登場しないので曖昧さの
  入り口がない
- **inline table 形式 (`{ any = [...] }`)**: 自己説明性と戦略オプションの
  後付け余地はあるが冗長。将来グループ単位の戦略指定が必要になったら、
  グループ位置に table も書ける形を**追加**すればよい (ネスト配列は
  その退化形として共存できるので、後付けが破壊変更にならない)
- **route 定義側に優先度を持たせる**: ns / モデル群ごとに優先度を変え
  られなくなる。振り分けの関心を route 定義に漏らすことになるため不採用
- **5h 窓も考慮する**: kawaz 裁定で不要。7d 枯渇だけが活動停止に直結する
- **残量 (utilization) を加味した重み付け**: リセット時刻だけで「先に
  消える枠から使う」の目的は達成できる。複雑化に見合わないため v1 では
  見送り (必要になったら別 DR)
