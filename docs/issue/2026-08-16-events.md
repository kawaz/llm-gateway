# events / usage の出力に denial の Reason を載せる

## 概要

events / usage の出力に denial の Reason を載せる (Reason::Paced が外から見えない)

## 背景

現状 denial の理由が `Reason::Paced` のような内部列挙のまま外部から確認できず、
events / usage 出力を見ても paced による denial なのか他の理由なのか判別できない。

## 受け入れ条件

- [ ] events / usage の出力に denial の Reason が含まれる
- [ ] Reason::Paced を含む各 denial 理由が外部から判別可能になる
